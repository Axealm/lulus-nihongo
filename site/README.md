# 記事(Panduan)

検索から人を呼ぶための、インドネシア語の記事。公開先は `https://lulusnihongo.com/panduan/`。Google Search Console に登録済み(2026-11-26)。記事を足したら、公開後に Search Console の「URL 検査」でその記事の登録をリクエストする(サイトマップは自動で読み直される)。

- 記事の本文: `site/articles/<スラッグ>.md`
- 運営者の説明など、一覧に出さないページ: `site/pages/<スラッグ>.md`(今は `tentang.md` だけ)
- 問題の見本ページ: 文章と設定は `scripts/build-articles.mjs` の中の `SAMPLE_SECTIONS`、問題は `content/` の各セクションの 1 つ目の練習セットから自動で作る
- ページを作るスクリプト: `scripts/build-articles.mjs`(`npm run build` と `npm run deploy` に含まれている)
- 出力先: `dist/panduan/<スラッグ>/index.html`、`dist/panduan/index.html`(一覧)、`dist/404.html`、`dist/sitemap.xml`、`dist/robots.txt`、`dist/og/<スラッグ>.png`(共有用の画像)

## 検索対策(SEO)として入れてあるもの

2026-11-26 に版 0.3.0 でまとめて入れた。新しいページを足すと、自動で同じ扱いになる。

| 対策 | 内容 |
|---|---|
| 問題の見本ページ | アプリの中の問題は検索から見えないので、各セクション 10 問(計 40 問)を、答えと解説つきの普通のページにした。入口は `/panduan/contoh-soal-jft-basic/`。聴解は音声と文字起こしつき。問題を直すと、次のビルドで見本にも反映される(文章を直したら `SAMPLE_UPDATED` の日付も変える) |
| 存在しないアドレス | `404.html` を置いた。これがないと、Cloudflare Pages はどのアドレスにもアプリの画面を「正常」として返してしまう。アプリは `#` を使う方式なので影響はない |
| 重複の解消 | `public/_headers` で、pages.dev のアドレスに「検索に載せない」の指定を付けた。正式な URL(canonical)は独自ドメイン |
| 目次とパンくず | 記事には見出しからの目次、すべてのページにパンくず(検索エンジン向けのデータつき) |
| 関連ページ | 各ページの最後に「Baca juga」として 3 件。どの記事からも見本の入口へ行ける |
| 構造化データ | 記事と見本は Article と BreadcrumbList、一覧は ItemList、トップは WebSite と WebApplication |
| 共有用の画像 | ページごとに題名入りの画像(1200×630)を作る。Windows のフォント(Segoe UI)を使うので、ほかの OS でビルドすると画像は作られず、アイコンで代用する |
| 運営者と編集方針 | `/panduan/tentang/`。お金や仕事の話題では、誰がどう書いているかが評価に関わるため |
| Google への登録 | Search Console に登録し、サイトマップを送信。新しいページを公開したら「URL 検査」で登録をリクエストする(1 日の回数に上限がある) |

まだやっていないこと(効果はあるが、時間か外部の協力が要る):

- **記事を増やす。** 順位にいちばん効く。候補は下の「次に書く候補」。
- **ほかのサイトからのリンク。** SNS の投稿、LPK や学校のサイトでの紹介など。
- **検索された言葉を見て直す。** 数日後から Search Console の「検索パフォーマンス」に数字が出る。表示はされるが押されない言葉があれば、題名と説明文を直す。
- **Bing などへの登録。** インドネシアでは Google の利用がほとんどなので後回し。

`npm run dev` では記事は表示されない。`npm run build` のあと `npm run preview` で確認する。

## 方針

人生の判断(仕事、お金、在留資格)に関わる話題なので、次を守る。

1. **事実には出典を付ける。** 公的機関か公式サイトだけを出典にし、記事の最後に「Sumber」として並べる。確認した日付も書く。
2. **確認できなかった数字は書かない。** 金額や条件を確認できないときは、数字を書かずに公式サイトへ案内する。
3. **誇張しない。** 「必ず合格」「高収入」などの表現は使わない。
4. **前向きに書く。ただし、判断に必要な事実は省かない。**(2026-11-26 にオーナーの指示で追加)
   - 不安をあおる書き方、否定的な結論で終わる書き方はしない。
   - 読者がお金や仕事の判断に使う事実(給料から引かれるもの、かかる費用、条件)は省かない。省くと、読者が来日後に損をし、景品表示法などの問題にもなりうる。
   - こうした事実は「知っておくこと」と「どう備えるか」をセットにして書く。例: 「2 年目に手取りが減って驚く人が多い」ではなく「住民税は 2 年目から。最初から計画に入れておけば安心」。
5. **必ず次の行動へ案内する。** どの記事も、勉強法の記事かアプリへつなげる。ページを作るスクリプトが、記事の途中、記事の最後、画面の下の 3 か所にアプリへの案内を自動で入れる。本文にも「次の一歩」の節を置く。
6. **意見と事実を分ける。** 学習計画などの助言は、公式の情報ではないことを記事の中に書く。
7. **薄い記事を量産しない。** 1 本ずつ、検索する人の疑問に最後まで答える内容にする。
8. **数字が変わる記事は見直す。** 見直したら `updated` の日付を変える。

## 広告リンク(アフィリエイト)

2026-11-26 に仕組みを用意した。**まだ 1 件も貼っていない**(提携先への登録はオーナーの作業)。

書き方: リンクの題名を `aff` にする。

```
[italki で日本語のレッスンを探す](https://www.italki.com/… "aff")
```

こう書くと、スクリプトが次を自動で行う。

- リンクに `rel="sponsored nofollow noopener"` を付け、新しいタブで開く(Google の指針に沿う)。
- リンクの横に「Iklan(広告)」の印を付ける。
- 記事の冒頭に「この記事には広告リンクがある。そこから申し込むと当サイトが報酬を受け取ることがある」という断り書きを入れる。

守ること:

1. **広告であることを隠さない。** 上の印と断り書きを消さない。日本のステルスマーケティング規制(景品表示法、2023 年 10 月〜)と、提携先の規約の両方が求める。
2. **確かめたことだけ書く。** 提携先の商品について、公式ページで確認できない効果や料金を書かない。
3. **読者の役に立つものだけ貼る。** 候補は、日本語の学習(オンラインレッスン、教材)、海外送金、通信。
4. **貼らないもの。** 仕事のあっせん業者や送り出し機関、ローン。読者から手数料を取る相手に送り込むことになり、職業紹介の許可の問題もある。
5. **無料の公式教材を先に紹介する。** 広告のために、いろどりなどの無料教材を隠さない。
6. 広告リンクは外部のサイトへの普通のリンクで、当サイトには計測のスクリプトを置かない。アプリの「個人情報を集めない」という説明と矛盾しない。

提携先の候補(2026-11-26 に調べた範囲。料率は登録後の管理画面で確かめること):

| 候補 | 内容 | 分かったこと |
|---|---|---|
| italki | オンラインの語学レッスン | 公式のヘルプでは、紹介した人の最初の購入で 10 ドル以上。登録は無料で、italki のアカウントが要る |
| Wise | 海外送金 | 紹介した人が最初の送金をすると報酬(金額は公式ページで確認できず)。審査がある。来日後の読者向け |
| Shopee / Tokopedia のアフィリエイト | インドネシアの通販 | インドネシアの身分証(KTP)と銀行口座が要るとする記事が多く、日本在住では登録できない可能性が高い(未確認) |

インドネシア語は AI が書いたもので、ネイティブの確認を受けていない。

## 記事の書き方

ファイルの先頭に、次の設定を書く。

```
---
title: 題名(インドネシア語)
description: 検索結果に出る説明(インドネシア語、170 文字以内)
date: 2026-11-25
updated: 2026-11-25
order: 3
summaryJa: オーナー向けの日本語の要約(1 行)
---
```

- ファイル名(スラッグ)が URL になる。半角の英小文字、数字、ハイフンだけを使う。公開したあとは変えない(URL が変わるため)。
- `order` の小さい順に一覧に並ぶ。
- 本文は Markdown で書く。題名(h1)は自動で入るので、本文は `##` の見出しから始める。
- 最初の段落を `<p class="lead">…</p>` にすると、少し大きい文字になる。
- `>` で始まる行は、注意書きの枠になる。
- ほかの記事へのリンクは `/panduan/<スラッグ>/` と書く。アプリへのリンクは `/`。
- アプリへの案内は自動で入る(3 つ目の見出しの前、記事の最後、画面の下の固定の帯)。
- 広告リンクは `[文字](https://… "aff")` と書く(上の「広告リンク」を参照)。

設定に不足や誤りがあると、`npm run build` が失敗して理由が表示される。

## 公開先の URL を変えるとき

独自ドメインにしたときは、環境変数 `SITE_URL` に新しい URL を入れてビルドする。`index.html` の canonical と og:url も直す。
